## Come aprire il progetto

1. Installa [Git LFS](https://git-lfs.com/) ed esegui `git lfs install` (una volta sola).
2. Clona il repository: i file `.blend` vengono scaricati tramite LFS.
3. Apri `Tower-LowPolyblend.blend` con Blender _[versione]_ o successiva.
